# packages/

Shared libraries used across apps/services. See
[../docs/01-Project/ProjectStructure.md](../docs/01-Project/ProjectStructure.md).

- `contracts/` — OpenAPI/proto + generated types (the seam between products) *(Phase 01+)*
- `common-py/` — shared Python utilities (config, logging, telemetry, auth) *(Phase 01)*
- `common-ts/` — shared TypeScript utilities + generated API client *(Phase 01+)*
