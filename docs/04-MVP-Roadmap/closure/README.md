# Milestone & Phase Closure

> **Purpose.** Home for **Milestone Closure Reports** and **Phase Completion Reviews**. The
> authoritative process, required contents, checklist, and status rules live in
> **CLAUDE.md §11**; this folder holds the artifacts it produces.

A milestone is `COMPLETE` only when its required technical **and** user documentation exist
and are verified. If implementation/tests/security are done but docs are not, the status is
**`DOCUMENTATION-INCOMPLETE`** (CLAUDE.md §11.8) — never `COMPLETE`.

## Naming

- Milestone Closure Report: `M0NN-<slug>-Closure.md` (e.g. `M001-Foundation-Closure.md`).
- Phase Completion Review: `PhaseNN-<slug>-Completion-Review.md`.
- `document_id`: `MVP-M0NN-CLOSURE` / `MVP-PNN-COMPLETION`.
